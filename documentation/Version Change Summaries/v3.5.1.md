# Vyxal 3.5.1

With a release of a major refactor, there will always be tiny little things that slipped under the radar. In this case, it was the fact that there were roughly 8 elements with glyphs that weren't in the codepage. If there wasn't a SBCS that'd be fine, but for code golf, it isn't.

Thus, this release fixes that:

- Remove `reduce lambda` to save a codepage slot (I was planning on removing it at some point anyway)
- Remove `empty string` constant (was `⑨`)
- Demote `✒` (`print without newline`) to be a digraph (`#,`) 
- Demote `ᖶ` (`if-else modifier`) to be a digraph modifier (`#⍰`)
- Remove `⎃` (`flatten and join on empty string`)
- Demote `✇` (`edges`) to be a digraph (`Þ⎶`)
- Demote `↳` (`retrieve from outer stack`) to be a digraph (`#↸`)
- Change `⟆` in the codepage to be one of the missing characters

The missing characters were `⊞γ‹›Ṫ×÷~`.

But this release isn't all silly bug fixes...the `--stdin` flag was added to set the inputs to the contents of STDIN. In other words, read the entirety of STDIN as if it were argv.

This is useful for when adding Vyxal to sites like https://byte-heist.com.

However, it isn't needed for when Vyxal is added to sites like https://code.golf/, which is a code golf website were you can use Vyxal 3 as an experimental language (it won't save submissions for now).

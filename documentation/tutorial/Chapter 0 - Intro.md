# Guide Chapter 0 - Introduction to Vyxal - An Somewhat Unconventional Tutorial

Hi there hello, the files within this directory serve to guide you, a programmer<sup>1</sup>, through the Vyxal 3 programming language. One might call
this a tutorial, but it's more of a guide rather than a series of steps on how to use the language. After all, programming languages aren't something you can just learn by following a series of steps. You need to understand the language, and that's what this guide is for.

## What is Vyxal?

Vyxal is:

- A stack-based language
- A tacit language<sup>2</sup>
- An array language<sup>4</sup> that moves beyond Iversonian paradigms
- A language that is designed to be terse and expressive (very good for code golfing - almost as if that was the original design goal)
- And most importantly, a language that is fun to use!

If none of that makes sense to you, that's okay. These terms will make sense as you move through this guide.

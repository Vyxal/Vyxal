# Vyxal 3

Vyxal is an array programming language that is:

- Stack-based
- Inherently terse
- and Convenient

## How do I run Vyxal 3?

There are a few methods:

1. Head over to [the online interpreter](https://vyxal.github.io/latest) (this is the easiest).

2. Download one of the release `jar` files, and run using

```
java -jar vyxal-jar <arguments>
```


3. Download the repository source and run with `./mill jvm.run`.
   See [Building.md](./contributing/Building.md) for more details.
